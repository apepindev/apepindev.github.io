## Users

Inferred, not confirmed: developers who land on a post from search while working on PHP, Laravel, Python or Node.js problems, plus peers and recruiters checking who Andrew is.

## Product Purpose

apepin.dev is Andrew Pepin's personal developer blog. The homepage states the job: "This is where I'll brain dump things I've learnt from work and personal projects." Success means a reader finds the answer in a post and recognises the author as a working backend engineer.

## Positioning

Written by a Senior Software Engineer at Kamma who works mainly in PHP/Laravel, with Python and Node.js. Posts come from real work and side projects.

## Operating Context

Static site built with Jigsaw (Blade, Markdown posts), Tailwind CSS 3, Laravel Mix, Vue 2 for search. Hosted on GitHub Pages at apepin.dev, deployed by `.github/workflows/publish.yml`.

## Capabilities and Constraints

- Pages: home, posts list, post, categories, About, Uses, 404, Atom RSS feed.
- Features: Fuse.js client-side search, light/dark toggle stored in localStorage, heading permalinks, highlight.js code blocks, optional post cover images, featured posts.
- Categories in use: configuration, feature, laravel, personal, php.
