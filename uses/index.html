What I use

Here's what helps me do my day-to-day.

Workstations

13-inch, M1, 2020 MacBook Pro

This is my personal machine. With 16GB memory and 512GB storage it has plenty of power for what I need it for.

16-inch, M1 Pro, 2021 MacBook Pro

This is my work machine and it's quite a bit more powerful! With a faster chipset, 32GB memory and 1TB of storage it makes light work with the software and containers I run.

Development software

JetBrains IDEs

My go-to IDE is anything by JetBrains. They all come pre-packed with tons of features that just make my life easier. Currently I'm using PhpStorm, PyCharm, GoLand and DataGrip.

Zed

When I just need a fast text editor rather than a feature rich IDE for scripts and small projects.

Ghostty/cmux

Pretty sure this is a common terminal alternative everyone uses on MacOS. The shell I use is a custom, lightweight variant of (Oh My Zsh).

OrbStack

A drop-in replacement to Docker for Mac, and a snappy one too. Works really well x86 emulation and requires less resources.

Bruno

The only "offline" API client with Git collaboration in mind. It's fairly new to the scene but it has already gained a lot of attention and works great.

Other software

Zen

Just recently made the switch from Arc (RIP) and I'm really impressed with it. It was quite a shift from a Chromium browser to a Firefox one but it's working great for me.

Boop

A neat text manipulation tool that already comes with an array of useful scripts. Really handy when I just need to do quick formatting.
